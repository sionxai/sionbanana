Risks

위험·막힘

확인된 사실과 미확인 영역을 분리

  • 후보 판정 대기 — local main 이력과 PPT는 feature에 보존됐지만 canonical 후보는 Checker 전이다. 완료·정본 승격을 선언하지 않는다.
  • NOW-005 산출물 보존 위험 — Webtoon 관련 미커밋 변경과 산출물이 존재한다. 정리·이동·삭제 전 보존 범위 확정이 필요하다.
  • 분석·배포 원천 부족 — 공개 URL과 GA4·Search Console·문의/예약/구매 실제 원천을 확인하지 못했다. 미수집 상태를 방문자나 매출 숫자로 바꿀 수 없다.
  • RTDB 확인 차단 — 마지막 2026-08-15 safe shallow GET은 DNS 경계로 응답을 받지 못했고 WO-003은 network 금지로 새 조회가 없다. 연결·데이터 유무·권한을 임의 판정하지 않는다.
  • 로컬 기록 해석 한계 — 관리자·개발·자동화·테스트 활동을 분리할 수 없고 원천 간 중복 가능성이 있다. 서로 다른 레코드 단위를 합산하지 않는다.
